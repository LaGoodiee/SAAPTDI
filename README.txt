SAAPTDI website (multi-page)

Upload EVERYTHING in this folder to GitHub, keeping the folder structure:
  index.html, about.html, team.html ... (one file per page)
  css/  js/  img/  video/  sitemap.xml  robots.txt  404.html

Web address used for search engines: https://saaptdi.com.ng/
If your site will live at a different address, replace that address in sitemap.xml, robots.txt and the
canonical / og:url / JSON-LD lines near the top of every .html file (find and replace works), then
submit sitemap.xml in Google Search Console and Bing Webmaster Tools.
